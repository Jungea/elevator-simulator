# Godot / Steam 프로토타입

Godot 4.x 기반의 웹 프로토타입 동기화 버전이다.

## 실행

Godot 4.x에서 `steam/project.godot`를 열고 프로젝트를 실행한다.

현재 환경에는 Godot 실행 파일이 없어 에디터 실행 검증은 아직 수행하지 못했다.

## 구현 범위

- 10층 건물, 3명 정원
- 목표층 선택 및 닫기 버튼 운행
- 층간 1.2초 이동
- 목적층/경유층 단계식 정차
- 하차 → 상태 차감 → 게임 오버 확인 → 대기 직원 탑승
- 중간 정차 후 닫기 버튼으로 재출발
- 정원 초과 대기층 통과
- 탑승자 및 대기 직원 UI

게임 규칙 기준은 루트의 `GAME_DESIGN.md`와 `logs/GODOT_STEAM_v0.1.0.md`를 따른다.
