# Web / Godot Prototype v0.1.1

- 기록일: 2026-10-30
- 변경: 통과층 이동거리 차감 동기화

## 변경 내용

- 정차 조건이 없는 통과층마다 탑승 중 일반 직원의 허용 이동거리를 1 차감한다.
- 통과 중 상태가 0 이하가 된 직원이 있으면 다음 정차층까지 진행하지 않고 즉시 게임 오버 처리한다.
- 통과층에서 차감한 거리는 이후 정차층 차감과 중복 계산하지 않는다.
- 웹 테스트에 통과층 상태 차감 회귀 케이스를 추가했다.
