# Godot / Steam Prototype v0.1.0

- 플랫폼: Godot 4.x / Steam 예정
- 상태: 웹 프로토타입 동기화 구현
- 구현 위치: `steam/`
- 기록일: 2026-10-30

## 구현 범위

- `project.godot` 및 메인 씬 구성
- GDScript 게임 상태 모델 구현
- 10층, 정원 3명, 대표 시작 탑승
- 목표층 선택 및 닫기 버튼 운행
- 층당 1200ms 이동
- 목적층과 경유층 단계식 정차
- 하차 → 상태 차감 → 게임 오버 확인 → 대기 직원 탑승 순서
- 중간 정차 후 닫기 버튼 재출발
- 정원 초과 대기층 통과
- 대기 직원/탑승자/층 버튼 UI

## 웹과 동기화한 규칙

- 현재 층 선택 불가
- 목적층 탑승자 하차 및 상태 차감
- 빈자리만큼 대기 직원 탑승
- 대기 중 목적층 비공개, 탑승 후 공개
- 상태가 0 이하이면 게임 오버
- 대표만 대표실에 도착하면 클리어

## 검증 상태

- GDScript 파일과 씬을 작성했다.
- 웹 규칙 테스트 7개는 통과했다.
- 현재 실행 환경에 Godot 4.x가 설치되어 있지 않아 Godot 에디터 실행/씬 로드 검증은 보류 상태다.
