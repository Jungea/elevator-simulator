# Web Prototype v0.1.0

- 플랫폼: Web
- 상태: 프로토타입 완성
- 기술: HTML, CSS, JavaScript ES Modules
- 배포: Vercel 정적 배포
- 데이터베이스: 사용하지 않음
- 기록일: 2026-10-30

## 범위

웹 브라우저에서 플레이 가능한 엘리베이터 퍼즐 게임 Release 0 프로토타입이다. 게임 규칙과 UI 흐름을 검증하기 위한 버전이며, Godot/Steam 버전은 아직 구현하지 않는다.

## 게임 규칙

- 10층 건물
- 시작 층은 1층
- 대표는 게임 시작부터 탑승
- 엘리베이터 정원은 3명
- 현재 층은 선택할 수 없음
- 목적층을 선택하고 닫기 버튼을 눌러 운행 시작
- 층간 이동은 층당 1200ms
- 이동 중 목적층 탑승자 또는 탑승 가능한 대기 직원이 있는 층에 정차
- 하차할 사람도 없고 빈자리도 없으면 대기층을 통과

## 정차 처리 순서

### 목적층

1. 층 도착 감지
2. 상행/하행 화살표 숨김
3. 목적층 탑승자 하차
4. 탑승자 UI에서 제거
5. 남은 이동 여유 차감
6. 상태가 0 이하인지 확인하고 게임 오버 처리
7. 빈자리가 있으면 대기 직원 탑승
8. 대기 인원 수 차감
9. 새 탑승자의 목적층과 상태 공개
10. 운행 종료 후 새 목적층 선택
11. 새 목적층 선택 시 닫기 버튼 활성화
12. 닫기 버튼 클릭
13. 새 목적층을 빨간색으로 표시하고 기존 목적층 표시 제거
14. 상행/하행 화살표 재표시 및 이동 중 점멸

### 경유층

1. 층 도착 감지
2. 상행/하행 화살표 점멸 정지 및 고정
3. 목적층 탑승자 하차
4. 탑승자 UI에서 제거
5. 남은 이동 여유 차감
6. 상태가 0 이하인지 확인하고 게임 오버 처리
7. 빈자리가 있으면 대기 직원 탑승
8. 대기 인원 수 차감
9. 새 탑승자의 목적층과 상태 공개
10. 닫기 버튼 활성화
11. 닫기 버튼 클릭
12. 상행/하행 화살표 점멸 재개

## UI 구현

- 대기 직원, 탑승자, 층 버튼 영역 분리
- 층 버튼은 둥근 사각형 형태
- 현재 층 버튼은 빨간 테두리·글자색
- 다음 목적층 선택 가능 버튼은 흰색 테두리 점멸
- 선택한 목적층은 노란색 테두리·글자색
- 운행 시작 후 목적층은 빨간색으로 전환
- 이동 중이거나 클릭할 수 없는 버튼에는 투명 딤 레이어 적용
- 현재 층 버튼은 클릭 금지 커서 표시
- 층수는 2자리 7세그먼트 디지털 숫자(`01`, `05`, `10`)
- 엘리베이터 층수와 방향 화살표는 빨간색 계열
- 이동 중 방향 화살표는 점멸
- 경유층 정차 중 방향 화살표는 고정
- 목적층 도착 시 방향 화살표 숨김
- 닫기 버튼은 ChevronRight + letter-i + ChevronLeft 조합
- 목적층 선택 상태와 경유층 정차 상태에서 닫기 버튼 테두리 점멸
- 탑승자는 세로형 ID 카드 스타일로 표시
- 직원 카드 테두리 색상은 상태에 따라 초록·노랑·빨강 적용
- 대표 카드는 실버/화이트 계열로 구분
- 직원 아바타는 이모지 스타일로 표시

## 코드 구조

```text
web/
├─ index.html
├─ styles.css
├─ vercel.json
├─ src/
│  ├─ game.mjs     # 게임 규칙 및 단계식 운행 상태
│  └─ main.mjs     # DOM 렌더링 및 입력 처리
├─ tests/
│  └─ game.test.mjs
└─ tools/
   └─ serve.mjs
```

## 테스트

실행 명령:

```powershell
node --test web/tests/game.test.mjs
```

현재 통과 항목:

- 현재 층 선택 차단
- 이동 경로 자동 정차
- 중간 정차 후 닫기 전 다음 층 진행 차단
- 목적층 탑승자 선 하차
- 정원 초과 시 대기층 통과
- 상태 0 이하 게임 오버
- 클리어 경로 존재

## 배포

Vercel 프로젝트 설정:

```text
Root Directory: web
Framework Preset: Other
Build Command: 비워 둠
Output Directory: 비워 둠
```

로컬 실행:

```powershell
node web/tools/serve.mjs
```

## 제한사항

- Godot 4.x/Steam 버전은 아직 구현하지 않음
- 로그인, 저장, 랭킹, DB 없음
- 고정 프로토타입 스테이지만 제공
- 아이콘은 Lucide CDN에 의존
